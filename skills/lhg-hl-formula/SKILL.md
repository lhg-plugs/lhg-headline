# lhg-hl-formula：标题公式库

> 目标：把"起标题靠灵感"变成"套公式+做选择"。
> 核心纪律：**一次至少用 3 个不同公式**给同一主题出标题，不许一个公式打天下。

## 1. 何时使用

- 用户给一个主题/一篇内容，说"帮我想个标题" → 先读本 skill
- 旧标题点击率差，要改写 → 先用公式拆解旧标题用了哪招、缺了哪招
- 一稿多发，要不同风格的标题 → 用不同公式各出一版

## 2. 输入与输出

**输入**：主题（一句话）或内容全文/摘要 + 可选：目标人群、平台、字数上限。
信息不足时只问**一个**最关键的问题（通常是"给谁看的"），不许连环追问。

**输出**：`titles.json`（见第 4 节格式）+ 每条的"公式标注"（用了哪几个公式、钩子落在前几字）。

## 3. 分步方法论：八大公式

### 公式一：数字量化
把模糊的"很多/很快"变成具体数字。数字是大脑的锚点。

- 结构：`[数字] + [单位] + [结果/事项]`
- 示例：`3 个习惯，戒掉第 2 个最难` / `存下这篇，7 天搞定年终总结`
- 注意：数字要**可验证**（内容里真有 3 个习惯）；"99%的人"这类无法验证的数字进标题党高危区（见 lhg-hl-compliance）。

### 公式二：痛点直击
说出读者最焦虑的那句话，让他觉得"说的就是我"。

- 结构：`[别再/踩坑/翻车/血亏] + [场景]`
- 示例：`别再瞎学 Python 了，先搞懂这 5 个概念` / `租房踩过的 4 个坑，第 3 个最贵`
- 注意：痛点词要有内容承接——点了进来发现文不对题，信任直接归零。

### 公式三：悬念钩子
制造信息差：让读者觉得"有个我不知道的事"。

- 结构：`[原来/居然/没人告诉你] + [反常识点]`
- 示例：`原来存钱最快的方法，是先把工资卡藏起来` / `做了 3 年运营，我才发现流量密码不在标题里`
- 注意：悬念必须在正文前 3 句揭晓一半，全部憋到最后 = 标题党。

### 公式四：对比反差
用"前后/彼此"的落差制造张力。

- 结构：`[以前…现在…] / [别人…我…] / [花 X 万 vs 花 X 块]`
- 示例：`以前月光，现在月存 5000，我只做对了一件事` / `同样的简历，改了 3 处，面试邀约翻了 4 倍`
- 注意：对比双方必须真实存在，虚构对比 = 欺诈风险。

### 公式五：人群点名
直接喊出目标读者，被点到的人很难不点进来。

- 结构：`[@人群] + [人群专属的收益/警告]`
- 示例：`打工人注意：这 3 个退税细节 90% 的人都漏了` / `新手妈妈收藏：夜奶断舍离的 4 个信号`
- 注意：点名要精准——"所有人"等于没点名；平台有人群词库限制时改用场景代替（见 lhg-hl-platform）。

### 公式六：结果承诺
给出可感知的收益，降低点击的心理成本。

- 结构：`[看完/存下/照做] + [具体结果]`
- 示例：`看完这篇，你也能写出不被骂的周报` / `照着做，30 天英语听力肉眼可见变好`
- 注意：承诺必须**可实现**（见 lhg-hl-compliance 第 3 节"承诺三问"）；做不到的承诺是最贵的标题。

### 公式七：反常识挑战
挑战读者固有认知，好奇心是最强的点击驱动。

- 结构：`[你以为…其实…] / [别被…骗了]`
- 示例：`你以为的存钱，是穷人思维的开始` / `别被"自律"骗了：真正高效的人都不早起`
- 注意：反常识要有论据支撑，否则就是抬杠；观点越极端，论据要求越高。

### 公式八：提问互动
用问题把读者拉进对话，评论区会替你传播。

- 结构：`[你…吗？] / [如果是你，你会…？]`
- 示例：`月薪 8000，你敢裸辞吗？` / `重来一次，你还会选这个专业吗？`
- 注意：问题要具体可答；"你觉得呢？"这种空问题没人理。

## 3.5 组合技：公式不是单选题

高点击标题通常是 2–3 个公式的叠加。常用组合：

| 组合 | 示例 | 适用 |
|---|---|---|
| 数字 + 痛点 | `5 个退税坑，第 3 个让 90% 打工人多交了税` | 干货/避坑类 |
| 悬念 + 对比 | `原来月薪 3 万的人，都在偷偷做这件"掉价"的事` | 观点/故事类 |
| 人群 + 结果承诺 | `新手爸妈收藏：3 招让宝宝一觉到天亮` | 母婴/教育类 |
| 反常识 + 数字 | `别再存钱了：3 个让钱越存越少的习惯` | 财经类（注意合规） |
| 提问 + 痛点 | `35 岁被裁员，你的存款够撑几个月？` | 职场/情绪类 |

**组合铁律**：钩子词必须落在**前 12 个字**内（移动端首屏焦点区），见 lhg-hl-platform 各平台字数表。

## 4. 输出格式：titles.json

```json
{
  "topic": "年终总结写作",
  "audience": "职场新人",
  "platform": "xiaohongshu",
  "titles": [
    {
      "text": "存下这篇，7 天搞定年终总结（附模板）",
      "formulas": ["数字量化", "结果承诺"],
      "hook_position": 1,
      "char_count": 16
    }
  ]
}
```

- `hook_position`：第一个钩子词出现的位置（第几个字），>12 要标 warning
- 一次输出 **5–8 条**，公式不重复优先
- 每条另起一行写 30 字内"创作要点"（钩子类型 + 适用场景）

## 5. 旧标题诊断（配合 headline-optimize 命令）

拿到旧标题先拆解：

1. 它用了哪几个公式？（多数平庸标题一个都没用）
2. 钩子落在第几个字？（>12 字就是"钩子迟到"）
3. 有没有"承诺>内容"？（标题党风险，见 lhg-hl-compliance）
4. 改写时保留原标题的**有效钩子**，只换公式组合——别把唯一的数据亮点也改没了

## 6. 反模式

- ❌ 一个公式套所有主题——读者 3 天就脱敏
- ❌ 数字无法验证（"99%的人都不知道"）——标题党高危
- ❌ 钩子藏在标题后半段——移动端根本看不到
- ❌ 承诺做不到（"看完月入十万"）——点击率越高，反噬越大
- ❌ 5 条标题全是同一公式换词——等于只给了一个选择

## 7. 自检与反馈

每次用完本 skill 自检：

1. 5–8 条标题是否用了 ≥3 个不同公式？
2. 每条钩子是否落在前 12 字？
3. 每条的数字/承诺在内容里找得到依据吗？

标准冒烟：跑 `scripts/audit/headline_audit.py` 扫 `fixtures/bad/titles.json`，确认标题党与极限词规则命中（见仓库根 `smoke_test.py`）。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-headline/issues，正文写清"主题 → 实际输出 → 期望输出"。公式库漏了常用公式请附 3 个真实例子。
