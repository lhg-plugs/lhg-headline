# lhg-hl-compliance：标题合规与敏感词检测

> 目标：标题发出去之前，先过一遍"法律+平台"的安检门。
> 核心纪律：**blocker 项不清零不许发布**——点击率再高的标题，违规了也是负分。

## 1. 何时使用

- 标题初稿出来后、发布前 → 必读本 skill + 跑审计脚本
- 用户说"这个标题会不会违规" → 按第 3–5 节逐项判定
- 做金融/医疗/教育类内容 → 第 4 节是重灾区，逐条过

## 2. 输入与输出

**输入**：候选标题列表（`titles.json`）+ 内容摘要（用于"承诺三问"）。
**输出**：每条标题的合规结论：通过 / warning（修或写豁免理由）/ blocker（必须改）。

## 2.5 检测分工：脚本查什么、人查什么

| 检测项 | 脚本（`headline_audit.py`） | 人工 |
|---|---|---|
| 极限词（最/第一/国家级） | ✅ 词表命中，blocker | 复核误报（如"最后一名"的"最"） |
| 医疗/金融绝对化 | ✅ 词表命中，blocker | 判断语境（"根治懒癌"是玩笑还是疗效承诺） |
| 标题党话术 | ✅ 高危话术命中 | 承诺三问（脚本看不懂"承诺>内容"） |
| 字数超限 | ✅ 按平台上限判定 | — |
| emoji/标点滥用 | ✅ 计数判定 | — |
| 关键词堆砌 | ✅ 重复计数 | — |
| 谐音规避（"蕞"替"最"） | ⚠️ 部分可查 | 主要靠人：看到就按恶意规避处理 |
| 标题与内容不符 | ⚠️ 仅当给了 content 字段时做关键词覆盖检查 | 必须人审：这是标题党判定的核心 |

**结论**：脚本是"安检仪"，人是"安检员"——仪器报警必须处理，仪器没报警不等于安全。

## 3. 分步方法论：四级安检

### 第一级：广告法极限词（blocker）

《广告法》第九条禁用的绝对化用语，标题里出现即 blocker：

- **级类**：最、第一、首个、首选、顶级、极致、巅峰、之最
- **全国类**：国家级、全球级、世界级、全国首家、全网第一
- **绝对类**：100%、绝无仅有、史无前例、前无古人、永久、唯一
- **欺诈类**：点击领钱、免费领取（实际有条件）、假一赔十（无法兑现）

改写方向：把绝对词换成**可验证的限定词**——"最便宜"→"比同级便宜 30%"（有比价依据），"第一"→"销量前三"（有榜单来源）。

### 第二级：行业绝对化表述（blocker）

| 行业 | 禁词示例 | 为什么 |
|---|---|---|
| 医疗/健康 | 根治、根除、治愈、药到病除、无效退款 | 医疗广告禁绝对化疗效 |
| 金融/理财 | 必涨、稳赚不赔、保本高收益、零风险 | 涉嫌承诺收益，监管红线 |
| 教育/考证 | 包过、保过、内部押题、不过退款（无资质） | 虚假承诺，平台严打 |
| 美妆/医美 | 一夜变白、7 天祛斑、纯天然无添加（绝对化） | 化妆品禁用医疗用语 |

### 第三级：标题党高危话术（blocker 或 warning）

标题党 = **承诺的信息增量 > 内容实际增量**。高危话术清单：

- 震惊体：`震惊！``万万没想到``出大事了`（无实质大事支撑 → blocker）
- 裹挟体：`不转不是中国人``再不看就晚了`（道德绑架 → blocker）
- 悬空体：`99%的人都不知道``最后一个绝了`（无法验证 → warning 起步）
- 断章体：标题截取内容中最极端的一句，以偏概全（→ blocker，需改写或补全限定）

**承诺三问**（每条标题自问）：

1. 点进来的人，3 分钟内能得到标题承诺的东西吗？
2. 标题里的数字/结论，内容里找得到出处吗？
3. 把标题给没看过内容的人看，他会产生**错误预期**吗？

三问有一问答不上来 → 降级改写，不许发布。

### 第四级补充：高风险行业发布前清单

金融、医疗、教育招生三类内容，标题定稿后人工逐项打勾：

- [ ] 标题里每个数字/结论，内容里都有出处（截图/链接/数据表）
- [ ] 没有"包/必/稳/根治"类绝对化表述（第二级清单全过一遍）
- [ ] 涉及收益/疗效/通过率的，标题旁有风险提示或限定条件
- [ ] 医疗类：不出现具体药名+疗效组合；不暗示"替代就医"
- [ ] 金融类：不出现具体标的+涨跌判断组合；有"不构成投资建议"意识
- [ ] 教育类：不承诺"包过/保录"；师资/通过率数字有来源

有一项打不上勾 → 回炉改写。**这三类标题出事，删文是最轻的后果。**

### 第四级：平台敏感词（warning）

- 小红书：`微信`（导流词）、`最`系极限词、医疗功效词
- 抖音：`钱`的直接表述（改"米"）、`国家`政策解读类慎用
- 公众号：`独家`（无信源慎用）、`内幕`（无依据慎用）
- 通用：地域歧视、性别对立挑唆类表述（流量有毒，品牌自杀）

## 4. 豁免流程

warning 项可以豁免，但必须**书面留痕**：

```
豁免：HL-CLICKBAIT-001 "99%的人都不知道"
理由：内容为作者 5000 份问卷实测数据，99% 有出处（见正文第 3 节）
豁免人/日期：____
```

blocker 项**不许豁免**，只能改写。为通过检测改审计脚本规则 = 作弊。

## 4.5 高频违规标题改写对照表

| ❌ 原标题 | 命中项 | ✅ 改写 |
|---|---|---|
| 全国最牛的英语培训，包过四六级 | 国家级+包过（双 blocker） | `四六级备考：这套方法帮 3000 人一次通过`（数字可验证，"帮"非承诺） |
| 一夜回春！7 天根治失眠 | 根治（医疗 blocker） | `失眠 3 年，我靠这 4 个习惯睡了整觉`（个人经验表述） |
| 稳赚不赔！这个基金闭眼买 | 稳赚不赔（金融 blocker） | `这只基金连续 5 年跑赢大盘，我研究了它的持仓`（事实陈述） |
| 震惊！99%的人都不知道的退税秘诀 | 震惊体+99%（blocker） | `退税多退 2000 的 3 个细节，很多人第一项就漏了` |
| 全网第一好吃的螺蛳粉 | 全网第一（极限词 blocker） | `嗦了 20 家螺蛳粉，这家汤底我愿排第一`（主观表达+限定范围） |
| 点击领取 100 元，不领后悔 | 欺诈类（有条件未说明） | `新用户首单立减 100 元（需绑定手机号）`（条件写进标题） |

改写心法：**把"绝对"换成"限定"，把"承诺"换成"事实"，把"裹挟"换成"选择"**。

## 5. 反模式

- ❌ "先发了再说，被投诉再删"——限流/封号成本远大于改标题成本
- ❌ 用谐音字绕检测（"最"→"蕞"）——平台语义识别比你想象的强，且属于恶意规避
- ❌ "别人都这么写"——别人没被罚不等于你不会被罚
- ❌ 金融/医疗标题让 AI 一把梭——这两个行业务必人工终审
- ❌ 豁免理由写"感觉没问题"——豁免必须有证据链

## 6. 自检与反馈

每次定稿前自检：

1. 跑 `scripts/audit/headline_audit.py`，blocker 必须为 0
2. 金融/医疗/教育类标题，人工逐条过第 3 节第二级清单
3. 承诺三问三问全过

标准冒烟：坏 fixture 的极限词/标题党/金融承诺埋点必须全部命中且脚本 exit!=0。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-headline/issues。极限词库漏词请附原标题 + 判定依据。

**免责**：本 skill 与配套脚本是启发式自查工具，不是法律意见；高风险行业（金融/医疗/药品/教育培训招生）发布前请咨询专业人士。
