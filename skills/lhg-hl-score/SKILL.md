# lhg-hl-score：点击率 rubric 打分

> 目标：用同一把尺子量所有候选标题，让"选哪个"不再靠拍脑袋。
> 核心纪律：**分数是排序工具，不是真理**——打分代替不了真实流量测试，但比感觉可靠。

## 1. 何时使用

- 候选标题有 5 条以上，不知道选哪条 → 用本 skill 打分排序
- 用户问"这个标题能打几分" → 按第 3 节 rubric 逐项给分
- A/B 测试前 → 先 rubric 粗筛，留 Top2 去实测

## 2. 输入与输出

**输入**：`titles.json` 候选列表 + 目标平台（决定字数项权重）。
**输出**：每条五维得分 + 总分（20 分制）+ 排序 + 每条一句话改写建议。

## 3. 分步方法论：五维 rubric（每维 0–4 分）

### 维度一：钩子强度（0–4 分）

钩子 = 让读者产生"必须点开"冲动的那个信息差。

| 分 | 标准 |
|---|---|
| 4 | 钩子在前 6 字，且是强信息差（反常识/高 stakes 数字/精准痛点） |
| 3 | 钩子在前 12 字，信息差明确 |
| 2 | 有钩子但位置靠后（12 字后）或信息差较弱 |
| 1 | 钩子模糊（"很好用的方法"——什么方法？） |
| 0 | 无钩子，平铺直叙 |

### 维度二：信息密度（0–4 分）

标题每个字都要干活。

| 分 | 标准 |
|---|---|
| 4 | 无一字可删；数字/人群/结果三要素齐了 |
| 3 | 删 1–2 字更紧凑 |
| 2 | 有 3 字以上冗余（"非常""真的""大家都知道"） |
| 1 | 一半字是废话 |
| 0 | 读完不知道讲什么 |

### 维度三：情绪唤起（0–4 分）

点击是情绪驱动的：好奇、焦虑、共鸣、愤怒、希望，至少命中一种。

| 分 | 标准 |
|---|---|
| 4 | 情绪具体且克制（"第 3 个最贵"——心疼且好奇） |
| 3 | 有情绪词但偏通用（"震惊""绝了"） |
| 2 | 情绪靠标点硬撑（"!!!"） |
| 1 | 情绪与内容脱节 |
| 0 | 白开水 |

注意：情绪分高但合规有风险的（标题党话术），**情绪分照打，合规项一票否决**——见维度五。

### 维度四：人群精准（0–4 分）

| 分 | 标准 |
|---|---|
| 4 | 点名具体人群或场景（"夜奶期的新手妈妈"），被点到的人必点 |
| 3 | 有人群词但偏宽泛（"打工人"） |
| 2 | 用场景代替人群，尚可（"租房时"） |
| 1 | "所有人""大家"——等于没点名 |
| 0 | 人群与内容错位（标题党式蹭人群） |

### 维度五：合规安全（0–4 分，一票否决项）

| 分 | 标准 |
|---|---|
| 4 | 过 lhg-hl-compliance 四级安检，零 warning |
| 3 | 1–2 个 warning，已写豁免理由 |
| 2 | 3 个以上 warning |
| 1 | 有 warning 未处理 |
| 0 | 有 blocker——**总分直接记 0，不许发布** |

### 维度权重：按内容类型微调

默认五维等权（各 20%）。以下内容类型建议调权，打分时注明：

| 内容类型 | 调权 | 理由 |
|---|---|---|
| 干货教程 | 信息密度 30%、钩子 25%、人群 20%、情绪 15%、合规 10% | 读者为"有用"而来，信息密度是留存关键 |
| 观点评论 | 情绪 30%、钩子 25%、合规 20%、信息 15%、人群 10% | 观点类靠情绪驱动传播，但合规权重同步拉高 |
| 带货种草 | 合规 30%、人群 25%、结果承诺（并入钩子）25%、信息 10%、情绪 10% | 极限词重灾区，合规一票否决最值钱 |
| 故事连载 | 钩子 35%、情绪 25%、信息 15%、人群 15%、合规 10% | 悬念是连载的命 |

调权后总分仍换算为 20 分制，报告里写清"本次权重"——不写权重的分数没有可比性。

## 4. 打分示例

标题：`存下这篇，7 天搞定年终总结（附模板）`（平台：小红书，16 字）

| 维度 | 得分 | 理由 |
|---|---|---|
| 钩子强度 | 3 | "7 天搞定"在前 8 字，信息差明确；非强反常识，扣 1 |
| 信息密度 | 4 | 无冗余；数字+结果+人群（隐含职场人）齐 |
| 情绪唤起 | 2 | "存下"有轻微焦虑感（怕找不到），偏弱 |
| 人群精准 | 2 | 未点名，"年终总结"场景代替人群 |
| 合规安全 | 4 | 零 warning（"搞定"非极限词，有模板为证） |
| **总分** | **15/20** | 改写建议：人群前置→`打工人存下：7 天搞定年终总结（附模板）`（人群+1，字数 19 仍合规） |

## 5. 排序与决策规则

1. 按总分降序；同分时**合规分高者优先**，再同分**钩子分高者优先**
2. 总分 <10 的标题直接淘汰，不进入 A/B 测试
3. Top2 分差 ≤2 分 → 两个都测（rubric 分辨率到头了，交给真实流量）
4. 每次只改**一个变量**做 A/B（换钩子词，或换人群词，不许全改）

## 5.5 低分标题急救：常见失分模式

| 症状 | 典型失分维度 | 急救（一句话改法） |
|---|---|---|
| `我的周报写作心得` | 钩子 0、信息 1 | 加数字+结果：`被总监夸的周报，我总结了 4 个套路` |
| `震惊！你一定要看！！！` | 合规 0（一票否决） | 删掉震惊体，换实质钩子：`周报多写这 3 行，涨薪谈判多 20% 底气` |
| `关于提升工作效率的一些方法分享` | 信息 1、钩子 1 | 具体化：`每天省出 2 小时：我的 5 个反效率习惯清单` |
| `所有人都该看看这篇` | 人群 1 | 点名：`刚入职的打工人，这篇能帮你少踩 3 个坑` |
| `3 个方法、5 个技巧、7 个习惯` | 信息 2（堆砌） | 只留一个最强数字：`7 个习惯里，第 3 个让效率翻倍` |
| 28 字的超长标题发小红书 | 平台适配失分 | 按 lhg-hl-platform 砍到 20 字内，钩子前置 |

急救顺序：先合规（一票否决）→ 再钩子位 → 再人群 → 最后抠字眼。

## 6. 反模式

- ❌ 唯分数论——"15 分一定比 14 分好"，rubric 误差约 ±2 分
- ❌ 为了冲分堆钩子词——"震惊！99%打工人不知道的 7 天秘诀"分高但 blocker，直接 0 分
- ❌ 不同平台用同一套权重——小红书人群分权重应更高，B站信息密度权重更高
- ❌ 打完分不写改写建议——分数的价值在于"怎么改"，不是"几分"
- ❌ 用 AI 打分代替人工终审——金融/医疗类标题务必人工复核

## 7. 自检与反馈

每次打分后自检：

1. 五个维度都给了分吗？理由写了吗？（无理由的分数 = 感觉）
2. 合规 0 分的标题，总分记 0 了吗？
3. Top2 分差 ≤2 分时，是否建议都实测？

标准冒烟：`headline_audit.py --format json` 输出的 findings 可作为合规维度的输入依据。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-headline/issues。rubric 权重建议请附 3 组对照标题与实测点击数据（如有）。
