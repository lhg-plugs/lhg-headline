# /lhg-headline:headline-optimize —— 旧标题诊断改写

用户输入在 `$ARGUMENTS` 中：`[旧标题] [--content 内容摘要]`。

加载 `lhg-hl-formula`（第 5 节诊断法）与 `lhg-hl-score`（第 5.5 节急救表）。

## 流程

### 1. 拆解旧标题
1. 它用了哪几个公式？（多数平庸标题一个都没用 → 病因"无钩子"）
2. 钩子落在第几个字？（>12 字 → 病因"钩子迟到"）
3. 承诺三问过吗？（过不了 → 病因"承诺超载"，标题党风险）
4. 人群/场景清晰吗？（"大家""所有人" → 病因"人群错位"）

输出"诊断单"：病因 + 证据（引用旧标题原文）。

### 2. 保留有效资产
- 旧标题里的数据亮点/有效钩子保留（如"7 天"这个数字是真的，就留着）。
- 只换公式组合，不推倒重来——别把唯一的数据亮点也改没了。

### 3. 改写
- 针对病因换 2–3 个公式重出 3–5 条，每条标注"治了哪个病因"。
- 走 `headline-audit` 合规 + `lhg-hl-score` 打分，新旧标题同台打分对比。

### 4. 交付
- 诊断单 + 改写版 + 新旧打分对照表。让用户看到"分涨在哪里"。

## 硬规则
- 不说病因直接给新标题 → 不许（下次还犯）。
- 改写版合规 blocker → 回炉，不许交付。
